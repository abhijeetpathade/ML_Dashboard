About the Project

Integrated Machine Learning Algorithm Dashboard

Project Objective

This mini project brings the machine learning algorithms implemented during the laboratory experiments into one web application. Users can select an experiment, understand its dataset and expected input/output, enter values, execute a model and review its prediction and performance.

Technologies Used

PythonApplication and model logic
FlaskWeb application framework
Pandas & NumPyDataset handling
Scikit-learnMachine learning algorithms
MatplotlibResult visualizations
HTML & CSSUser interface

Experiments Included

  1. Dataset Understanding
  2. Simple Linear Regression
  3. Multiple Linear Regression
  4. Binary Logistic Regression
  5. Multiclass Logistic Regression
  6. Decision Tree
  7. K-Nearest Neighbors
  8. Naive Bayes
  9. Linear SVM
  10. Non-Linear SVM
  11. Random Forest
